## Featured Projects

### ForecastLess

Context-aware GenAI weather decision engine that turns forecast data into scenario-specific actions using local LLMs via Ollama.

Built around practical decision support rather than generic weather summaries.

### PromptLens

A prompt-diff and analysis tool for understanding how prompt changes affect model outputs.

Focused on making prompt behavior easier to inspect, compare, and reason about.

### Beyond Naive Prompts

A practical exploration of where simple prompting breaks and how better structures can fix it.

Built around the idea that reliable AI systems need more than clever wording.

### DeepSkyAgent

An adversarial astrophotography planner built around planning logic and AI-assisted decision support.

Focused on reasoning under constraints instead of just generating generic recommendations.
